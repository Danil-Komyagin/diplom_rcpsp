# RCPSP – Resource-Constrained Project Scheduling Problem

Разработка системы планирования ресурсно ограниченных задач с использованием нейронных сетей и графового классификатора на основе анализа структуры проекта

## Описание

Desktop и Web формат, БД с возможностью сохранять решения
Автоматический выбор алгоритма графовым классификатором
Система эвристик, метаэвристик, точных и нейросетевых методов для решения RCPSP в одном приложении
Визуализация при помощи диаграммы Ганта, импорт и экспорт проектов и отчетов

## Назначение проекта

Проект предназначен для project-менеджеров, руководителей производства, специалистов по планированию.
Проект решает проблему планирования, позволяя сформировать план работы на основании списка задач и доступных ресурсов.
