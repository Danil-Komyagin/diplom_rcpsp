# 📊 MRCPSP – Multi-Mode Resource-Constrained Project Scheduling Problem

Дипломная работа по теме: "Разработка программы для планирования работ с множественными ресурсами (MRCPSP)".

## 📋 Описание

Планировщик проектов с ограниченными ресурсами, составляющий расписание с помощью параллельного эвристического алгоритма.

## 🚩 Назначение проекта

Проект предназначен для руководителей IT-разработки.
Проект решает проблему планирования, позволяя сформировать оптимизированный план работы на основании списка задач и доступных человеческих ресурсов.

## 🔠 Возможности программы

Программа позволяет:
- Создавать проекты с множественными ресурсами (разработчики, тестировщики, дизайнеры и др.)
- Добавлять задачи с длительностью, зависимостями и потреблением ресурсов
- Автоматически строить расписание с использованием параллельного эвристического алгоритма
- Визуализировать результаты в виде диаграммы Ганта и графиков использования ресурсов
- Сравнивать эффективность различных правил приоритета (LPT, SPT, MTS, GRPW, MS)

## 🚀 Установка и запуск

```bash
# 1. Клонируем репозиторий
git clone https://github.com/ТВОЙ_ЛОГИН/diplom_rcpsp.git
cd diplom_rcpsp

# 2. Создаём виртуальное окружение
python -m venv venv

# 3. Активируем
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. Устанавливаем зависимости
pip install -r requirements.txt

# 5. Запускаем
python main.py
```
