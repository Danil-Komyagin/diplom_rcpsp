# 📊 MRCPSP - Планировщик проектов с ограниченными ресурсами

Дипломная работа по теме: "Разработка программы для планирования работ с множественными ресурсами (MRCPSP)".

## 📋 Описание

Программа позволяет:
- Создавать проекты с множественными ресурсами (разработчики, тестировщики, дизайнеры и др.)
- Добавлять задачи с длительностью, зависимостями и потреблением ресурсов
- Автоматически строить расписание с использованием параллельного эвристического алгоритма
- Визуализировать результаты в виде диаграммы Ганта и графиков использования ресурсов
- Сравнивать эффективность различных правил приоритета (LPT, SPT, MTS, GRPW, MS)

## 🛠️ Технологии

- **Python** 3.8+
- **Tkinter** — графический интерфейс
- **Matplotlib** — визуализация
- **NumPy** — численные расчёты
- **JSON** — хранение проектов

## 🚀 Установка и запуск

```bash

source venv/bin/activate

# 4. Устанавливаем зависимости
